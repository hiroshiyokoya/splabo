# geartoon 用語辞書

UI 表示・コード変数・将来の多言語対応（i18n キー）を一元管理するドキュメント。
UI を変更するときや翻訳ファイルを作るときはこの辞書を参照し、表記を統一すること。

| 頭装備 | 頭ギア（タブ）/ 頭（短縮） | あたまのギア | `'head'` | `category.head` |
| 服装備 | 服ギア（タブ）/ 服（短縮） | からだのギア | `'clothing'` | `category.clothing` |
