# リリース前スモークテスト

タグ push・ドラフト Publish の前に、**出荷バイナリ（または同等の release ビルド）**で確認する。開発ビルド（`0.0.0-dev`）だけでは足りない。

方針は [#535](https://github.com/hiroshiyokoya/splabo/issues/535)。α / β は出さない。Android viewer は使わない（スマホは Web 版）。

CI（clippy / `cargo test --lib`）が通っていることは前提。このリストは「実機で見えること」用。

## すべてのリリースで

### ビルド成果物

- [ ] About（このアプリについて）の版表示が、打つ予定のタグ（例: `1.0.0`）と一致する
- [ ] 開発ビルド扱いになっていない（版が `0.0.0-dev` でない。stat.ink アップロードが設定どおり動く余地がある）
- [ ] Windows: `.exe`（推奨）と `.msi` の両方を入れられる（または少なくとも一方で起動確認）
- [ ] macOS（Apple Silicon）: `.dmg` から起動できる
- [ ] Linux: `.deb` または `.rpm` から起動できる（どちらか手元で確認できれば可）

### 起動・データ

- [ ] 初回起動（データなし）で落ちない
- [ ] 任天堂ログイン → バトル取得 → ダッシュボードが表示される
- [ ] ギア取得 → ギア一覧・コーデ生成ができる
- [ ] パネル保存（PNG / HTML）ができる
- [ ] 旧バージョンからの上書きインストール（または MSI）で、戦績・ギア・設定が残る

### スマホで見る（同じネットワーク）

- [ ] 設定 →「スマホで見る」をオンにすると QR が出る
- [ ] スマホのブラウザで QR を開き、戦績またはギアが見える
- [ ] Windows でネットワークが Public のとき、設定に直し方の案内が出る（該当する場合）

### 案内・法務（画面と文書）

- [ ] About に既知の制限へのリンク、ライセンス（MIT / AGPL サイドカー）がある
- [ ] README・紹介ページのダウンロード導線が最新リリースを指す（prerelease を掴まない）

## OS ごとのメモ

| OS | 必須か | メモ |
|----|--------|------|
| Windows | 必須 | 主戦場。SmartScreen の回避はリリースノート末尾どおり |
| macOS (Apple Silicon) | 必須 | Intel Mac 版は出さない（既知の制限） |
| Linux (.deb / .rpm) | できれば | AppImage は出さない。手元に環境が無ければ「WF 成果物の起動は次のメンテナ」と明記してよい |

## やらないこと（このリストの範囲外）

- コード署名・公証・Tauri 自動更新の確認（入れない方針）
- Android viewer のペアリング
- AppImage / Intel Mac 向けビルド
