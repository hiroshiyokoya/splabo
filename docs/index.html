ギアトゥーン (geartoon)

Splatoon 3 Gear Wardrobe

Nintendo アカウントで認証し、非公式 API 経由で所持ギアを取得・表示する非公式ファンツールです。
スキル・ブランドで絞り込んだり、目標スキルからコーデ候補を自動生成できます。

ダウンロード

Windows / macOS 対応  ·  無料

スクリーンショット

所持ギアを一覧表示

スキル・ブランドで絞り込み

目標スキルからコーデを自動生成

できること

ギア一覧・絞り込み

  • 頭・服・靴タブで一覧表示
  • スキル・ブランドで絞り込み
  • ブランド / ギアパワー / 名前 などで並び替え

コーデ生成

  • 目標スキルを指定してコーデ候補を自動生成
  • 発動型スキルにも対応
  • 「惜しい候補」も表示

データ取得

  • Nintendo アカウント認証でワンクリック取得
  • データはローカルに暗号化保存
  • インターネット接続は更新時のみ

カスタマイズ

  • カラーテーマ 3種類
  • 表示密度の切り替え
  • 候補件数の設定

インストール時の注意

Windows — SmartScreen 警告が出た場合

「Windows によって PC が保護されました」と表示されたら、「詳細情報」→「実行」をクリックしてください。

macOS — 「壊れているため開けません」と表示された場合

ターミナルで以下を実行してください：
xattr -cr /Applications/geartoon.app

プライバシーについて

本ツールが外部に送信するのは、Nintendo 認証に必要な情報のみです（nxapi の仕様に基づくもので、geartoon 独自の送信はありません）。氏名・メールアドレス等の個人情報を収集・記録することはありません。
