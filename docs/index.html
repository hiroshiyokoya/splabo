スプラボ (splabo)

Splatoon 3 の戦績可視化・分析とギアコーデ

Nintendo アカウントから非公式 API 経由で Splatoon 3 の戦績とギアを取得し、可視化・分析する OSS の PC アプリです。任天堂株式会社とは無関係です。
ブキ・ステージ・ルール別の勝率、線・棒・散布図・ヒートマップのカスタムグラフ、stat.ink 公開データによる環境分析、ギアコーデができます。
パネルは PNG や HTML に保存できます。旧 chartoon / geartoon の後継です。

できること

バトル・ダッシュボード

  • バトル履歴を一覧（検索・フィルター・ソート）。詳細で編成・ギア・ランク変動を確認
  • 期間・ロビー・ルール・結果で絞り込める
  • 勝率・キル/デス・キルレシオなど主要指標を、ブキ・ステージ・ルール・モード別に集計
  • カスタムグラフ: 線・棒・散布図・ヒートマップ・カレンダー。散布図はブキ画像にもできる
  • パネルは PNG / HTML で保存可能

自動取得・連携

  • 15 分〜24 時間ごとの自動取得（既定は 1 時間。バトル＋ギア・トレイ常駐・完了通知）
  • stat.ink への自動アップロード（s3s 互換、UUID v5 で重複排除）

AI 分析

  • 自然言語で聞くと SQL を書かせ、集計はこの PC の中だけで実行して表・グラフで表示
  • OpenAI / Gemini / Claude / Grok に対応

ブキ・ステージ・ギア

  • ブキ・ステージ: 勝率や戦績。カテゴリ / サブ / スペシャルで絞り込み、列クリックで並び替え
  • ギア: 所持ギアの取得・一覧。ギアパワーを組み合わせてコーデを作成

環境分析

  • stat.ink の公開バトルデータからコミュニティ全体の環境を分析
  • ブキ・ステージ別の散布図、マトリクスヒートマップ
  • ロビー・ルール・ブキ・ステージ・バージョン・ウデマエ帯・期間で絞り込み

インストール時の注意

Windows — SmartScreen 警告が出た場合

「Windows によって PC が保護されました」と表示されたら、「詳細情報」→「実行」をクリックしてください。

macOS — 「壊れているため開けません」と表示された場合

ターミナルで以下を実行してください：
xattr -cr /Applications/splabo.app

注意事項

  • 本アプリは任天堂株式会社とは無関係の非公式 OSS アプリです。
  • SplatNet 3 は任天堂が公式に公開している API ではありません。任天堂側の仕様変更により、予告なく動作しなくなる可能性があります。
  • ブキ・ステージ画像の著作権は任天堂株式会社に帰属します。個人利用の範囲内でのみ使用してください。
  • 認証情報・バトルデータはお使いの PC 内にのみ保存されます。stat.ink へのアップロードは設定で有効化したときのみ行われます。

プライバシーについて

本ツールが外部に送信するのは、Nintendo 認証に必要な情報（nxapi の仕様に基づく f-token 生成）と、設定で有効にした場合の stat.ink へのバトルデータのみです。氏名・メールアドレス等の個人情報を収集・記録することはありません。

AI 分析機能を使用する場合は、選択したプロバイダ（OpenAI / Gemini / Anthropic / Grok）へバトル集計データが送信されます。

詳細は プライバシーポリシー（README） を参照してください。
