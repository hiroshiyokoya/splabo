splabo

Splatoon 3 battle stats, analysis, and gear loadouts

An open-source Windows / macOS app that fetches Splatoon 3 battles and gear from a Nintendo Account via an unofficial API, then visualizes and analyzes them. Not affiliated with Nintendo Co., Ltd.
Win rates by weapon, stage, and mode; custom line, bar, scatter, and heatmap charts; meta analysis from public stat.ink data; and gear loadouts.
Save panels as PNG or HTML. Successor to chartoon / geartoon.

What you can do

Battles and dashboard

  • Browse battle history (search, filter, sort). Details show team composition, gear, and rank changes
  • Filter by period, lobby, mode, and result
  • Win rate, K/D, kill ratio, and more by weapon, stage, mode, and lobby
  • Custom charts: line, bar, scatter, heatmap, calendar. Scatter plots can use weapon images
  • Save panels as PNG or HTML

Auto-fetch and integrations

  • Auto-fetch every 15 minutes–24 hours (default 1 hour; battles + gear, tray icon, completion notification)
  • Auto-upload to stat.ink (s3s-compatible, UUID v5 dedup)

AI analysis

  • Ask in natural language; SQL is generated and aggregated only on this PC, then shown as tables and charts
  • OpenAI / Gemini / Claude / Grok

Weapons, stages, and gear

  • Weapons and stages: win rates and records. Filter by category / sub / special; sort by column click
  • Gear: fetch owned gear and combine abilities into loadouts

Meta analysis

  • Analyze the community meta from public stat.ink battles
  • Scatter plots and matrix heatmaps by weapon and stage
  • Filter by lobby, mode, weapon, stage, version, rank band, and period

Install notes

Windows — if SmartScreen warns you

If you see “Windows protected your PC”, click More info → Run anyway.

macOS — if it says the app is damaged

Run this in Terminal:
xattr -cr /Applications/splabo.app

Notes

  • This is an unofficial open-source app, not affiliated with Nintendo Co., Ltd.
  • SplatNet 3 is not a public Nintendo API. Nintendo may change it without notice and the app may stop working.
  • Weapon and stage image copyrights belong to Nintendo Co., Ltd. Use them for personal use only.
  • Auth tokens and battle data stay on your PC. Uploads to stat.ink happen only when you enable them in Settings.

Privacy

The only data this tool sends off your PC is what Nintendo auth needs (f-token generation per the nxapi flow) and, if you enable it, battle data to stat.ink. It does not collect or store names, email addresses, or other personal information.

If you use AI analysis, battle aggregates are sent to the provider you chose (OpenAI / Gemini / Anthropic / Grok).

See the privacy policy in README_en.md for details.
